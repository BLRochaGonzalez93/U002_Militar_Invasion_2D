# Militar Invasion 2D Visual Pack

[English](README.en.md) | [Español](README.md)

Imágenes previstas para el proyecto **Militar Invasion 2D**.

Este directorio está preparado para incluir los recursos visuales del proyecto en versiones originales y optimizadas para web.

## Contenido previsto

### original-png/

Versiones PNG separadas desde el mockup o artes originales.

- `militarinvasion-logo.png`
- `militarinvasion-cover.png`
- `militarinvasion-banner.png`
- `militarinvasion-thumbnail-01-player-shooting.png`
- `militarinvasion-thumbnail-02-enemy-waves.png`
- `militarinvasion-thumbnail-03-mecha-spider-boss.png`
- `militarinvasion-thumbnail-04-level-selection.png`

- `militarinvasion-logo.webp`

- `militarinvasion-thumbnail-01-player-shooting.webp`

## Uso recomendado

- `militarinvasion-logo.webp` para identidad del proyecto.
- `militarinvasion-cover.webp` para Open Graph, portada y redes.
- `militarinvasion-banner.webp` para la web portfolio.
- Las miniaturas para cards, documentación, README o previews técnicas.

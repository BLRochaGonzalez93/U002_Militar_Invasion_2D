# Militar Invasion 2D Visual Pack

[English](README.en.md) | [Español](README.md)

Planned images for the **Militar Invasion 2D** project.

This directory is prepared to include the project's visual assets in original and web-optimized versions.

## Planned contents

### original-png/

PNG versions separated from the mockup or original artwork.

- `militarinvasion-logo.png`
- `militarinvasion-cover.png`
- `militarinvasion-banner.png`
- `militarinvasion-thumbnail-01-player-shooting.png`
- `militarinvasion-thumbnail-02-enemy-waves.png`
- `militarinvasion-thumbnail-03-mecha-spider-boss.png`
- `militarinvasion-thumbnail-04-level-selection.png`

### webp/

The same images converted to `.webp` for web usage.

- `militarinvasion-logo.webp`
- `militarinvasion-cover.webp`
- `militarinvasion-banner.webp`
- `militarinvasion-thumbnail-01-player-shooting.webp`
- `militarinvasion-thumbnail-02-enemy-waves.webp`
- `militarinvasion-thumbnail-03-mecha-spider-boss.webp`
- `militarinvasion-thumbnail-04-level-selection.webp`

### _source/

Original complete composite image, in PNG and WEBP.

- `militarinvasion-generated-composite.png`
- `militarinvasion-generated-composite.webp`

## Recommended usage

- `militarinvasion-logo.webp` for project identity.
- `militarinvasion-cover.webp` for Open Graph, cover and social sharing.
- `militarinvasion-banner.webp` for the portfolio website.
- Thumbnails for cards, documentation, README files or technical previews.
